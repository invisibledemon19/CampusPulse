# CampusPlus

CampusPlus helps college students find free and affordable hackathons, internships, workshops and offline events, ranks them by an explainable fit score, and tracks deadlines and application progress.

## Features

- Discover opportunities: Search hackathons, internships, workshops and events filtered by category, cost, format and city.
- Explainable fit score: 0 to 100 score calculated by fixed rules matching your skills, education level, city, format and budget.
- Nearby offline events: Filter in-person and hybrid events by travel distance and maximum registration fee.
- Opportunity Passport: Track saved opportunities, next steps with checklists, application status and personal notes.
- Profile management: Store education level, skills, interests, city and budget preferences.
- Privacy focused: Works offline and locally with browser storage in demo mode.

## Tech stack

- React 19
- Vite
- Tailwind CSS v4
- React Router v7
- Lucide React icons
- IBM Plex Sans self-hosted typography
- Vitest

## Getting started

### Prerequisites

Node.js 22 or newer.

### Installation

```bash
npm install
```

### Development server

```bash
npm run dev
```

### Running tests

```bash
npm run test
```

### Production build

```bash
npm run build
```

The build script automatically generates robots.txt and sitemap.xml, runs the design QA checks, bundles assets, and verifies the initial JavaScript budget is under 150 KB gzip.
