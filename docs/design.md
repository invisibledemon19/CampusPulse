# CampusPlus design specification

Audience for this file: the frontend agent (Gemini 3.8 Flash in Antigravity, as named by the project owner). Read this file and `architecture.md` completely before writing any code. Where this file and a default habit of the model disagree, this file wins.

Product summary: CampusPlus helps college students find free and affordable hackathons, internships, workshops and offline events, ranks them by an explainable fit score, and tracks deadlines and application progress.

## 1. Hard bans

Every item below is a release blocker. The agent must not add any of them, even as a placeholder.

| Banned | Do this instead |
| --- | --- |
| Purple, violet, indigo or any gradient anywhere | Flat colors from the palette in section 4 |
| Vague hero text (for example "Discover your future") | Concrete H1 from the copy deck in section 10 |
| Fake reviews, testimonials, ratings, avatars of "students" | Omit the section entirely |
| Fake metrics ("10,000+ students", "500+ events", uptime claims) | Show only counts computed from real data on screen, such as "Showing 12 of 18 opportunities" |
| Heavy scroll animation (reveal on scroll, parallax, sticky transforms, scroll-linked effects) | Static layout. No IntersectionObserver animation code |
| Pill-shaped buttons or badges (`rounded-full`, `rounded-3xl`) | Corner radius of 6px for controls, 8px for cards, 4px for badges |
| Emoji used as icons or decoration, anywhere in UI, copy, console or README | `lucide-react` icons, imported one by one, always paired with a text label or an accessible name |
| Cursor animation, custom cursors, trailing effects | Browser default cursor. `cursor-pointer` only on real links and buttons |
| AI generated images, stock illustrations, hero art | Typography, borders, flat color blocks and icons only. No photographs |
| Em dashes (U+2014) and en dashes (U+2013) in any visible text, code comments, markdown or metadata | Use a comma, a colon, a full stop, a hyphen, or the word "to" for ranges |
| "Made with AI", "Built with Gemini", "Powered by Claude", "Generated by", Vite or Antigravity credits | No credit line. No `<meta name="generator">` |
| AI sounding copy (see banned vocabulary in section 9) | Plain, specific sentences from the copy deck |
| Dark patterns, countdown pressure, "only 2 spots left" claims | Show the real deadline date and the real days left |
| Lorem ipsum or placeholder text in any shipped screen | Real copy from this file |

## 2. Brand

- Name: CampusPlus (one word, capital C and capital P).
- The tagline "Stop searching. Start showing up." is not used in the hero. It may be used once in the footer or in the README. Do not repeat it elsewhere.
- Tone: direct, factual, student to student. Short sentences. Say what a thing is and what it costs.

## 4. Color tokens

Light theme only for the MVP (`color-scheme: light`). Define tokens in `src/index.css` using Tailwind v4 `@theme`. Do not create a `tailwind.config.js`.

```css
@import "tailwindcss";

@theme {
  --color-canvas: #F7F8FA;
  --color-surface: #FFFFFF;
  --color-ink: #111827;
  --color-muted: #4B5563;
  --color-line: #D1D5DB;

  --color-brand: #0F766E;
  --color-brand-hover: #115E59;
  --color-brand-soft: #E6F4F1;

  --color-warn-bg: #FEF3C7;
  --color-warn-ink: #92400E;
  --color-danger-bg: #FEE2E2;
  --color-danger-ink: #B91C1C;
  --color-success-bg: #DCFCE7;
  --color-success-ink: #166534;

  --radius-control: 6px;
  --radius-card: 8px;
  --radius-badge: 4px;

  --font-sans: "IBM Plex Sans", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
}

:root { color-scheme: light; }
html { scroll-behavior: auto; }
```

Rules:

- Text on `canvas` or `surface` is `ink` or `muted`. Text on `brand` is white. Warning text is `warn-ink` on `warn-bg`. Closed or error text is `danger-ink` on `danger-bg`.
- Color never carries meaning alone. Every status has a text label.
- The listed pairs were chosen to meet 4.5:1 contrast. Re-check with a contrast tool before launch and fix any pair that fails.
- No gradients, no box shadows heavier than `shadow-sm`, no glassmorphism or blur.

## 5. Typography

- Family: IBM Plex Sans, self-hosted through `@fontsource/ibm-plex-sans`. Do not load fonts from Google Fonts or any CDN.
- Import only what is used: `latin-400.css`, `latin-500.css`, `latin-600.css`, plus `latin-ext-400.css` and `latin-ext-600.css` so that the rupee sign renders in the intended font. The browser downloads a subset file only when its characters appear on the page.
- QA check: open a listing with a fee and confirm the rupee sign looks consistent with the surrounding text. If it falls back to a system font and looks wrong, change the font family for numerals only, do not add more font weights.
- Scale: body 16px, small 14px, H1 32px (28px under 640px), H2 22px, H3 18px. Line height 1.5 for body, 1.25 for headings. Maximum line length for legal pages: 72 characters (`max-w-prose`).
- One H1 per page. Heading levels never skip.

## 6. Shape, buttons and badges

- Buttons: radius `6px` (`rounded-control`), minimum height 44px, horizontal padding 16px, font weight 500.
- Primary button: `brand` background, white text, `brand-hover` on hover. Secondary: white background, 1px `line` border, `ink` text. Destructive: white background, `danger-ink` text and border.
- Badges: radius `4px`, 12px text weight 500, padding 2px 8px, always text. Never `rounded-full`.
- Cards: `surface` background, 1px `line` border, radius 8px, padding 16px (20px from 768px up).
- Inputs: 44px minimum height, 1px `line` border, radius 6px, visible label above the field. Placeholder text is a hint only, never the label.
- Focus: every interactive element shows `outline: 2px solid #0F766E; outline-offset: 2px` on `:focus-visible`. Never remove outlines without replacing them.
- Lint rule to add: fail the build if `rounded-full` or `rounded-3xl` appears in `src`.

## 7. Icons

- Library: `lucide-react`. Import each icon by name from the package root, for example `import { MapPin } from 'lucide-react'`. Never import the whole namespace, never use `import * as`.
- Size 16px inline with text, 20px in buttons, stroke width 1.75, `aria-hidden="true"` when a text label sits next to it.
- Icon only buttons need `aria-label`.
- Suggested mapping: Discover `Compass`, Nearby `MapPin`, My Opportunities `Bookmark`, My Profile `User`, deadline `CalendarClock`, fee `IndianRupee`, external link `ExternalLink`, verified `BadgeCheck`, unverified `CircleHelp`, warning `TriangleAlert`, filter `SlidersHorizontal`, close `X`. If a name does not exist in the installed version, pick another lucide icon, never an emoji.

## 8. Motion

- Allowed: color and border-color transitions on hover and focus, 150ms ease-out. Opening and closing of the mobile filter panel with no animation or a 150ms opacity change.
- Not allowed: scroll-triggered effects, parallax, looping animation, typewriter text, animated counters, cursor effects, page transition animation, animated gradients.
- Wrap any transition in `@media (prefers-reduced-motion: no-preference)`.
- Loading state: static skeleton blocks in `line` color, no shimmer.

## 9. Copy rules

Write every string as a student would read it on a phone. Use the strings in section 10 exactly. Do not rewrite, embellish or "improve" them.

Banned vocabulary (do not use in any visible string, comment, README or meta tag): seamless, seamlessly, unlock, empower, leverage, elevate, supercharge, revolutionize, cutting-edge, game-changing, next-level, journey, delve, tapestry, landscape (as a metaphor), curated, tailored, hassle-free, one-stop, all-in-one, "in today's fast-paced world", "take your career to the next level", "we are passionate", "dive in", "level up".

Other rules:

- Say "fit score", never "AI score" or "AI match". The score comes from fixed rules and uses no AI model.
- Missing data is shown as "Not provided". Never guess a fee, date, venue or link.
- Use sentence case for headings and buttons. No exclamation marks. No ALL CAPS except the rupee symbol and abbreviations such as NCR.
- Currency format: `₹500`, `Free` for zero. Dates: `15 Nov 2026`. Use `Intl.DateTimeFormat('en-IN', ...)` through `utils/dates.js`.

Titles are at most 60 characters. Meta descriptions are at most 155 characters. Each page has a unique title, description and H1. Pages marked noindex also get `<meta name="robots" content="noindex,follow">` through the `usePageMeta` hook (see `architecture.md`).

## 11. Layout

- Container: `max-w-6xl`, horizontal padding 16px (24px from 768px).
- Desktop (1024px and up): left filter column 260px, results grid 2 columns. Tablet: filters in a collapsible panel above results, 2 columns. Mobile: single column, filter panel opened by a "Filters" button.
- Navigation: top header on all sizes with brand on the left. Under 640px the four section links move to a fixed bottom bar with icon and label, each target 44px high. Add bottom padding to `main` so content is not hidden behind the bar.
- Header and footer appear on every route including 404.
- A "Skip to main content" link is the first focusable element.
- Landmarks: `header`, `nav` (with `aria-label`), `main` (with `id="main"`), `footer`.

## 12. Components

Reusable components in `src/components/`: `Navbar`, `Footer`, `OpportunityCard`, `MatchScore`, `SearchFilters`, `Badge`, `Button`, `TextField`, `SelectField`, `TagInput`, `EmptyState`, `ErrorState`, `DemoBanner`, `DeadlineLabel`, `Checklist`, `StatusSelect`.

- `MatchScore` shows the number, the tier label and a 6px high flat bar (radius 2px) in `brand`. If the score is null, show "Fit score unavailable. Add your profile." and no bar.
- `OpportunityCard` order: badges row (category, cost, format, demo or verified), title (link to detail), organizer and city, `MatchScore`, up to 2 reasons, deadline label, then actions (Save, View details).
- Deadline urgency is a separate badge from the fit score. `warn` colors for 3 days or fewer, `danger` colors for closed.
- Every form validates on submit and on blur, shows the message under the field, links the message with `aria-describedby`, and moves focus to the first invalid field.
- Every button must perform its action. If a feature is not built, remove the button instead of leaving it inert.

## 13. Custom 404 page

Two layers, both required:

1. `public/404.html`: a standalone static file with inline CSS, no JavaScript, the same palette and font stack (system fallback is fine), `<meta name="robots" content="noindex">`, the favicon links, a unique title ("Page not found | CampusPlus"), an H1 ("Page not found"), the line "The page you asked for does not exist or has moved.", and two links: "Go to Discover" (`/`) and "View Nearby" (`/nearby`). Vercel serves this file with HTTP status 404 for paths that match no file and no rewrite (see `architecture.md`).
2. `src/pages/NotFound.jsx`: the same content as a React route (`path="*"`) for client-side navigation. It uses `usePageMeta` with `noindex`.

Also render the in-app not found state on `/opportunity/:id` when the id does not exist, with the H1 "Opportunity not found" and a link back to Discover.

## 14. Accessibility checklist

- Keyboard: all actions reachable with Tab, Enter and Space. Filter panel and any dialog trap focus and close with Escape.
- Every input has a visible label. Every icon only control has an accessible name.
- Status changes (saved, removed, profile saved, filter result count) are announced with `aria-live="polite"`.
- Touch targets at least 44x44px.
- Text can be zoomed to 200 percent without horizontal scroll. Tables or long content scroll inside their own container.
- Page language: `<html lang="en">`.

## 16. Design QA checklist (run before every demo and before launch)

1. Search the whole project for banned items: `grep -rnE -e $'\xe2\x80\x94' -e $'\xe2\x80\x93' src public index.html README.md` must return nothing. `grep -rnE "rounded-full|rounded-3xl|gradient|violet|purple|indigo" src index.html` must return nothing.
2. `grep -rniE "lorem|made with|powered by|generated by|vite \+ react|antigravity|gemini|claude" src public index.html` must return nothing visible to users.
3. Search for the banned vocabulary list in section 9 across `src`.
4. No emoji characters in `src`, `index.html`, `public` or the README.
5. Every route has a unique title, description and H1. Check with the browser tab and the Elements panel.
6. Tab through every page with the keyboard only.
7. Open every page at 360px, 768px and 1280px widths. No horizontal scroll.
8. Confirm `/this-does-not-exist` returns the custom 404 with HTTP status 404 (see `architecture.md`).
9. Confirm the favicon appears in the tab and all icon files load.
10. Confirm the demo banner shows whenever demo listings are visible and that no demo listing claims to be verified.
